回复内容（可编辑）
生成后的 3 条候选会先进入可编辑草稿窗。你可以自由修改，确认满意后再点击对应的「填入 X」。
英文推文自动使用自然英文回复，不写翻译腔。
中文推文自动生成短、狠、像真人的中文短评。
API 设置
切换渠道会自动加载该渠道上次保存的 Key、模型、Base URL。
自定义渠道下，Base URL 请填写完整 endpoint，例如 https://api.deepseek.com/anthropic/v1/messages。
支持填根域名或带 /v1 的 Base URL，扩展会自动补全；末尾加 # 可强制按完整 URL 处理。
