# X 推文互动回复器 v2.0

X 推文互动回复器是一个用于 X / Twitter 的 Chrome 扩展。

## v2.0 更新

- 点击 `AI回` / `AI填入` 后一次生成 3 条回复候选
- 右下角草稿窗提供 3 个可编辑文本框
- 每条候选都可以单独复制或填入 X
- 接口返回 HTML / 非 JSON 时会直接提示 Base URL 配置问题，不再静默显示固定兜底句
- 额外提示词只作为风格参考，插件固定控制输出数量和 JSON 格式

## 保留能力

- 融入半透明二次元初音风底图
- 高端玻璃拟态 UI
- 设置页顶部保留：作者：BigQiang & Akiii | @iBigQiang，@Guomin184935
- 生成后先进入「可编辑草稿窗」
- 可先手动修改，再点击「填入 X」
- 只填入回复，不自动发送
- 点击插件图标会打开独立设置页，不再使用会自动关闭的弹出设置框
- 英文推文自动使用英文回复
- 中文推文自动使用中文回复
- 继续支持 OpenAI / API2D / 兼容 Chat Completions
- `fk` 开头 Key 自动识别为 API2D

## 安装方式

1. 解压 zip
2. 打开 Chrome：`chrome://extensions/`
3. 打开右上角「开发者模式」
4. 点击「加载已解压的扩展程序」
5. 选择 `BigQiang-X-reply-extension` 文件夹
6. 点击插件图标，填写 API Key 并保存
7. 刷新 X 页面使用

## 使用方式

- 时间线推文旁边会出现 `AI回`
- 打开回复框后，工具栏旁边会出现 `AI填入`
- 点击生成后，会弹出可编辑草稿窗
- 选择其中一条，改满意后，再点击对应的 `填入 X`
